# Code of Conduct

veil adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, in its published wording. It applies to everyone in
every project space: issues, pull requests, discussions, reviews and any
other channel that represents the project.

In short: be respectful and constructive, assume good faith, and critique
ideas, not people. Harassment, insults, sexualized language or imagery,
publishing someone's private information, and other conduct that is
unacceptable in a professional setting are not allowed.

## Reporting

Report a problem privately to the maintainer (see [GOVERNANCE.md](GOVERNANCE.md))
with GitHub's **Report content** option on the comment, issue or pull
request, which reaches the repository's maintainers. For something that is
not tied to one piece of content, open a private report through
[GitHub private vulnerability reporting](https://github.com/FullFran/veil/security/advisories/new)
and start its title with "Code of conduct"; it is visible only to the
maintainer. Reports are kept confidential.

## Enforcement

The maintainer reviews every report within 14 days and applies the
Contributor Covenant 2.1 enforcement guidelines (correction, warning,
temporary ban, permanent ban), in proportion to the impact. A report about
the maintainer goes to GitHub through **Report abuse** on the maintainer's
profile.
